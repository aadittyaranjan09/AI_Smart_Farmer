🌾 AI Smart Farmer

AI Smart Farmer is a web-based platform designed to help farmers make smart decisions using modern technologies like AI, APIs, and real-time data.

🚨 Problem Statement

  • Farmers lack real-time weather information
  • Difficulty in identifying crop diseases
  • No proper crop recommendation system
  • Limited access to smart farming tools

💡 Solution

AI Smart Farmer provides an all-in-one dashboard that integrates multiple smart farming tools in a simple and user-friendly interface.

✨ Features

  • 📍 Farm Location Detection (Geolocation API)
  • 🌤 Real-time Weather Updates (OpenWeather API)
  • 🌱 AI Crop Recommendation
  • 🧪 Soil Health Tips
  • 📷 Crop Disease Detection (AI Concept)
  • ⚠️ Weather Alerts
  • 🔐 Firebase Authentication (Google Sign-In)
  • 🌙 Dark/Light Mode

🛠 Tech Stack

  • Frontend: HTML, CSS, JavaScript
  • Backend: Firebase
  • APIs: OpenWeather API, Geolocation API
  • Charts: Chart.js
